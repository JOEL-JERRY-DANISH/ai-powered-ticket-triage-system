## 8. Root Cause Summary

| Finding | Evidence |
|---------|----------|
| **Labels randomly assigned** | Chi-square p ≈ 0.98 for all features; every cross-tab ≈ 20% uniform |
| **Text synthetically generated** | 100% contain `{placeholder}` tokens; top fragments repeat 180–6000× |
| **No real-world customer text** | Descriptions contain random web filler, forum spam, product listing noise |
| **No feature predicts the target** | Text, subject, channel, status, age, product — all statistically independent of Ticket Type |
| **Dataset not suitable for supervised ML as-is** | Any model will converge to ~20% (random chance for 5 balanced classes) |

## 9. Recommended Next Step

> [!IMPORTANT]
> **The dataset cannot be fixed by changing models, features, or hyperparameters.**
> The label-feature relationship does not exist because the labels were randomly generated.

### Option A — Replace the Dataset ⭐ (Recommended)
Use a **real** customer support ticket dataset such as:
- [Zendesk/Freshdesk exports from your own organisation]
- [Kaggle: Customer Support on Twitter](https://www.kaggle.com/datasets/thoughtvector/customer-support-on-twitter)
- [CLINC150](https://github.com/clinc/oos-detect) — intent classification with real text
- [Banking77](https://huggingface.co/datasets/PolyAI/banking77) — 77 banking intents, real queries

The existing pipeline (`ColumnTransformer` + `TfidfVectorizer` + `LogisticRegression`) is production-ready and will achieve 80–90%+ accuracy on a real labelled dataset with no further changes.

### Option B — Reframe the Task
Use `Ticket Subject` as the label to predict from `Ticket Description`. Since both are generated from the same template, subject-keyword overlap may provide weak but non-random signal — and the architecture serves as a clean demo.

### Option C — Use as Architecture Demo Only
Keep the current dataset and pipeline strictly as a **proof-of-concept** for the hackathon presentation. Be transparent: *"The architecture is production-ready; this synthetic dataset was used for demonstration only."*
